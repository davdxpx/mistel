# Adapters

What Mistel knows about a game engine. A finding that holds for every game on one engine (where its objects live, how it names them, how its frame limit works) is written once in the engine's adapter, so that cheats, mods and companions for all of its games can use it.

| Adapter | Engine versions | Status |
|---|---|---|
| [`unreal/`](unreal/) | Unreal Engine 4.23 and later | Planned, first |
