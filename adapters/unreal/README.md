# Unreal Engine adapter

The first adapter, for Unreal Engine 4.23 and later. Many Switch games run on these versions and share one layout of the engine's name pool and object array, so one adapter can serve all of them.

What it will cover:

- Finding the name pool and the object array in a game's memory.
- Walking objects by class and name, instead of by fixed address.
- The engine's console variables, such as the frame limit.
