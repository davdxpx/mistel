# The `.mncf` specification

The specification of the Mistel Native Cheat Format lives here, one file per major version: `mncf-1.md` for `mncf/1`.

It is being written. Until it is merged, nothing in Mistel reads or writes `.mncf` files, and the format can still change.

A change to the format starts here ([CONTRIBUTING.md](../../CONTRIBUTING.md#before-you-start)): the spec first, with the version rule it follows, then every reader in the same pull request.
