# Lab

The test loop on a real Android handheld. A change to a cheat, a mod or a companion is only done when it ran on a device.

- Install a test build of the emulator, never the player's own install.
- Start a game on a copy of a save, run a scenario (turn a cheat on and off, press a button, wait), and collect the log.
- Restore the test build's state afterwards, so the next run starts clean.
- Where a device is shared, take it and give it back with a lock; never by force.
